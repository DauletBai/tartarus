Расчёт без ИИ: ресурсы, потребности и сроки

В новом расчётном слое я сохраняю прежнюю экономическую цель: обеспечение потребностей независимо от занятости. Замена способа вычисления не меняет права человека. Для каждой территории, категории ресурса и периода задаю запас s, производственные действия x, пригодный выпуск Bx, расход сырья Ax, подтверждённое обеспечение y и потери w. Тогда:

sₜ₊₁ = sₜ + Bxₜ − Axₜ + прибытиеₜ − отправкаₜ − yₜ − wₜ.

Каждая строка этого равенства относится к своей физической единице. Выпуск появляется в период завершения производства; отправленный груз — в период фактического прибытия. Положительный учётный остаток не заменяет вещь, которой ещё нет.

Ограничения мощности, труда и энергии записываю отдельно. Матрицы C, L и E описывают их расход на производственные действия; K, H и U — доступные объёмы:

Cxₜ ≤ Kₜ; Lxₜ ≤ Hₜ; Exₜ ≤ Uₜ.
sₜ ≥ 0; xₜ ≥ 0; 0 ≤ yₜ ≤ nₜ.

Здесь n — согласованная потребность. Для сравнения равномерности покрытия положительных потребностей можно ввести общую долю z и искать её наибольшее допустимое значение при yᵢ ≥ z·nᵢ и 0 ≤ z ≤ 1. Срочные медицинские и другие жизненно важные назначения требуют отдельных согласованных ограничений. Максимальная средняя обеспеченность сама по себе не защищает человека, которому не досталось ничего.

Последовательность целей я задаю явно: сначала жизненно необходимые условия, затем наименьшая обеспеченность среди групп, далее оставшиеся потребности, потери и лишние изменения уже принятого плана. Это порядок исследовательского сравнения. Его нельзя незаметно заменить максимизацией денежного оборота.

Для обращения Теңге использую вектор остатков b и вектор целочисленных переводов q. Матрица D показывает, какой счёт отдаёт и какой получает меру; сумма каждого её столбца равна нулю. Отдельный вектор e содержит только явно разрешённое изменение общего количества меры:

bₜ₊₁ = bₜ + Dqₜ + eₜ.
Σbₜ₊₁ = Σbₜ + Σeₜ.

При обычной циркуляции e равен нулю. Повтор команды не создаёт второй перевод. Резервирование связывает учётное исполнение с доступностью ресурса. Правила разрешения эмиссии остаются самостоятельным предметом общественного решения; приведённое равенство не даёт программе права выпускать меру по собственному усмотрению.

Уравнение (I − A)x = f из предыдущей модели является частным агрегированным случаем. Для него нужна продуктивная согласованная матрица затрат; ограничения мощностей, сроки и неопределённость вводятся дополнительно. Современное математическое программирование позволяет решать такие задачи без языковой модели. При нехватке ресурсов результатом должна стать видимая невыполнимость или явно согласованная очередность, а не скрытое уменьшение записанной потребности.
