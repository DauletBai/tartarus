Первая условная числовая проверка

Для P005390 предполагается, что запись reverse1.1.a — итог, а1.1.b1 и1.1.b2 — составляющие. Это предпосылка, которую нужно проверять по расположению и другим документам.

Итог:       2·N45 + 5·N14 + 3·N01
Часть1:     1·N45 + 7·N14
Часть2:             8·N14 + 3·N01

Если итог = часть1 + часть2, то вес(N45) = 10·вес(N14).

При весах моделиŠE: N01=1, N14=6, N45=60:

153 = 102 + 51

При весах моделиS: N01=1, N14=10, N45=3600, сумма не сходится:7253 ≠3670+83. Это различает две модели при принятой предпосылке итог/части. ОтношениеN14/N01 не выведено из одной таблички — оно взято из внешней модели.

Вторая проверка без назначения числовых весов

На другом предмете, P005366, состав редакторских числовых классов сохраняет точную сумму:

obverse1.1.b:   2·N18
obverse1.2.b:   4·N03 + 1·N40
reverse1.2:    2·N18 + 4·N03 + 1·N40

2A + (4B + C) = 2A + 4B + C

Это проверка структуры конкретных записей. Успех равенства не означает, что независимо установлено чтение каждого клина, название товара или язык писца. Алфавит и полный перевод не получены.
