Малый опыт с доказуемым решением

Для двух производственных способов из главы 26 обозначу их объёмы x и y, запасы зерна и энергии G и E, мощности a и b. Максимизирую x + y, а при равном результате выбираю меньший расход энергии:

2x + y ≤ G; x + 2y ≤ E.
0 ≤ x ≤ a; 0 ≤ y ≤ b; x + y ≤ 200.
x, y — целые числа.

При G = E = 240 и a = b = 100 сложение первых двух ограничений даёт 3(x + y) ≤ 480. Поэтому предел равен 160. Решение x = y = 80 достигает его и тем самым доказуемо оптимально. Программная проверка дополнительно перебирает малые сочетания запасов, мощностей и спроса и сравнивает ответ с независимым полным перебором допустимых пар.

Этот пример не содержит скрытого прогноза и не обращается к платному сервису. Воспроизводимость расчёта означает совпадение результата при одинаковых условиях, а не достаточность этих условий для описания всех отношений общества.
